What is enforced

  • Exact sender allowlist and a mandatory subject PIN
  • IMAP over TLS, with the mailbox password encrypted at rest
  • Attachment size, count, and PDF page limits
  • UID deduplication so a seen message is not printed twice
  • Rejected mail is kept in the event log, not described as healthy
  • Dashboard actions require the signed-in session and a request token
